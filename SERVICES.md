# Подключение сервисов

Все внешние сервисы — по желанию: без них пайплайн работает (локальный whisper, ролики без звуковых акцентов или с вашими собственными звуками). Интервью (`setup`, блок 4) проводит по этому файлу по одному сервису за раз и проверяет каждый, прежде чем перейти к следующему.

## Как устроен доступ

Два способа, и ни в одном ключ не попадает в git и в чат:

| способ | сервисы | где хранится | как отозвать |
|---|---|---|---|
| **API-ключ** | ElevenLabs, 21st.dev, Buffer, Dropbox | `video/.env` — в `.gitignore`; 21st.dev — ещё и в локальных настройках Claude Code (`~/.claude.json`, только для этой папки) | удалить ключ в кабинете сервиса |
| **Вход через браузер (OAuth)** | Higgsfield, ElevenLabs MCP | у Claude Code, не в проекте; в `.mcp.json` только адреса серверов | `/mcp` → сервер → Clear authentication + отозвать приложение в настройках сервиса |

Правила, которых держится агент:
- **Ключ вы вписываете сами** в `video/.env` (открыть: `open -e video/.env` на Mac). Не присылайте ключ в чат — агент его не просит и никогда не печатает.
- После каждого сервиса агент запускает `bash video/scripts/doctor.sh` — раздел `access` показывает, работает ли ключ и подключён ли MCP.
- Всё, что тратит кредиты (генерации, Scribe), агент делает только с вашего согласия и называет цену заранее.
- Публикация — сначала черновик; опубликовать или поставить в расписание — только после вашего «да» на конкретный пост.

**Где делается `/mcp`.** Это команда внутри Claude Code в терминале (`claude` в папке проекта). Если в десктоп-приложении её нет — откройте терминал в папке проекта, запустите `claude`, выполните `/mcp`, войдите в нужные сервисы и вернитесь в приложение: авторизация сохраняется. Первый запуск после появления `.mcp.json` спросит, доверять ли серверам из него, — ответьте «да» для тех, что выбрали.

## ElevenLabs — расшифровка, звуки, озвучка

**Зачем:** Scribe — расшифровка речи с таймкодами по словам (вместо локального whisper); генерация звуковых акцентов в том характере, который вы выберете (звуков в проекте нет); озвучка.

**Стоимость:** есть бесплатный тариф с небольшим запасом кредитов; Scribe и генерации тратят кредиты.

1. Зарегистрируйтесь на https://elevenlabs.io.
2. Откройте https://elevenlabs.io/app/settings/api-keys → создайте ключ.
3. **Ограничьте ключ**, если кабинет это предлагает: оставьте доступ только к Speech to Text, Sound Effects и Text to Speech, поставьте месячный лимит кредитов. Чем уже права — тем меньше вреда, если ключ утечёт.
4. Скопируйте ключ (показывается один раз) и впишите в `video/.env`:
   ```
   ELEVENLABS_API_KEY=ваш_ключ
   ```
5. Скажите агенту «готово» — он проверит: `doctor.sh` покажет `ElevenLabs key  works` (или `works (restricted key)` для ограниченного ключа).

MCP-сервер ElevenLabs (`https://api.elevenlabs.io/v1/mcp`, вход через браузер) — по желанию, если хотите, чтобы агент работал с голосами и аудио ElevenLabs напрямую; для пайплайна хватает ключа.

**Отозвать:** удалите ключ на странице API keys.

## Higgsfield — б-ролл и вставки

**Зачем:** генерация коротких видеовставок (б-ролл), когда спикер описывает то, что можно показать. В ролике — максимум ~3 штуки, агент показывает их стикером `Clip`.

**Стоимость:** генерации платные (кредиты Higgsfield). Агент спрашивает перед каждой и называет цену.

1. Зарегистрируйтесь на https://higgsfield.ai и при необходимости пополните кредиты.
2. Агент добавит сервер в `.mcp.json`: `"higgsfield": { "type": "http", "url": "https://mcp.higgsfield.ai/mcp" }`.
3. Перезапустите Claude Code в папке проекта → разрешите сервер из `.mcp.json` → `/mcp` → **higgsfield** → Authenticate → войдите в браузере и разрешите доступ.
4. Проверка: `doctor.sh` → `MCP higgsfield  connected` (или `claude mcp list` → `✓ Connected`).

**Отозвать:** `/mcp` → higgsfield → Clear authentication; удалите строку из `.mcp.json`.

## 21st.dev — компоненты для графики

**Зачем:** библиотека React-компонентов; агент берёт их как основу для новой графики (карточки, интерфейсы, анимированные элементы) и переводит на Remotion.

**Стоимость:** есть бесплатный лимит, дальше — подписка.

1. Зарегистрируйтесь на https://21st.dev.
2. Создайте ключ на https://21st.dev/mcp.
3. Впишите в `video/.env`:
   ```
   TWENTYFIRST_API_KEY=ваш_ключ
   ```
4. Агент добавит сервер локально — ключ читается из `.env` прямо в команде и не попадает ни в чат, ни в репозиторий:
   ```bash
   cd video && set -a && . ./.env && set +a && cd .. && claude mcp add --transport http 21st https://21st.dev/api/mcp --header "x-api-key: $TWENTYFIRST_API_KEY" --scope local
   ```
   Если команды `claude` нет в PATH (десктоп-приложение) — выполните эту строку сами в терминале в папке проекта.
5. Перезапустите Claude Code. Проверка: `doctor.sh` → `21st.dev key  works` и `MCP 21st  connected`.

**Отозвать:** удалите ключ на 21st.dev и `claude mcp remove 21st -s local`.

## Instagram: Buffer + Dropbox — выкладка готового ролика

**Зачем:** готовый ролик сам выходит в Reels в назначенное время, с подписью. Агент готовит подпись и пост, публикует или ставит в расписание только после вашего «да».

**Почему два сервиса.** Buffer публикует в Instagram и держит расписание, но файл не принимает: он скачивает ролик по ссылке в момент публикации. Ссылка должна быть публичной и прямой, то есть отдавать сам файл, без страницы просмотра. Dropbox даёт такую ссылку (`dl.dropboxusercontent.com/…`), а после выхода поста агент удаляет файл, чтобы место не кончалось.

**Стоимость:** у Buffer есть бесплатный тариф на несколько каналов. Dropbox Basic бесплатно даёт 2 ГБ, ролики лежат там только до выхода поста.

### 1. Instagram и Buffer

1. Instagram должен быть профессиональным аккаунтом: в приложении «Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт», тип «Автор» или «Бизнес».
2. Зарегистрируйтесь на https://buffer.com и подключите Instagram в самом Buffer (Channels → Connect). Там же можно подключить TikTok и YouTube.
3. Ключ API: https://publish.buffer.com/settings/api → создайте ключ и впишите в `video/.env`:
   ```
   BUFFER_API_KEY=ваш_ключ
   ```
4. Скажите агенту «готово». Он выполнит `python3 video/scripts/publish_buffer.py channels` и покажет ваши каналы. Если Instagram-аккаунтов несколько, id нужного впишите в `BUFFER_CHANNEL_ID=`.

### 2. Dropbox

1. Зарегистрируйтесь на https://www.dropbox.com, если аккаунта нет.
2. Откройте https://www.dropbox.com/developers/apps → **Create app**:
   - API: **Scoped access**;
   - доступ: **App folder** (приложение видит только свою папку `Приложения/<имя>`, остальной Dropbox ему недоступен);
   - имя любое, например `reels-upload-<ваше имя>` (имя должно быть уникальным во всём Dropbox).
3. Вкладка **Permissions** — отметьте `files.content.write`, `files.content.read`, `sharing.write`, `sharing.read` и нажмите **Submit**. Права ставятся до входа: если войти раньше, ключ получится без них и вход придётся повторить.
4. Вкладка **Settings** — скопируйте **App key** и **App secret** (Show) в `video/.env`:
   ```
   DROPBOX_APP_KEY=…
   DROPBOX_APP_SECRET=…
   ```
5. Скажите агенту «готово». Он выполнит `python3 video/scripts/publish_dropbox.py login` и даст ссылку. Откройте её, нажмите «Разрешить», Dropbox покажет код. Код впишите в `video/.env` строкой `DROPBOX_AUTH_CODE=…` (в чат не присылайте) и скажите «готово».
6. Агент выполнит `publish_dropbox.py connect`: код меняется на постоянный ключ `DROPBOX_REFRESH_TOKEN`, сам код стирается. Код живёт несколько минут и срабатывает один раз; не успели — повторите с шага 5.

### 3. Проверка

`bash video/scripts/doctor.sh` → строки `Dropbox` (имя вашего аккаунта) и `Buffer key` (сколько каналов) со статусом `ok`. Пробный пост агент не публикует: первый настоящий пойдёт через «опубликуй», с вашим «да».

**Отозвать:** Buffer — удалить ключ на странице API; Dropbox — https://www.dropbox.com/account/connected_apps → отключить приложение, или удалить само приложение в App Console.

## Instagram — для референсов (без подключения)

Ссылки на рилсы агент скачивает `yt-dlp` (`brew install yt-dlp`) — только для разбора, в `takes/refs/`, в git не попадают и никуда не публикуются.

- Публичные рилсы обычно скачиваются без входа.
- Если Instagram требует вход или ограничивает частоту — два варианта:
  1. **С вашего согласия** агент перезапустит с `COOKIES_FROM=chrome` (или `safari`, `firefox`): `yt-dlp` локально прочитает куки браузера, где вы уже вошли в Instagram. Ничего не сохраняется в проект и не уходит никуда, кроме Instagram. На Mac система может спросить доступ к связке ключей — это нормально.
  2. Скачайте рилсы сами (любым способом) и положите mp4 в `takes/refs/` — агент разберёт файлы.
