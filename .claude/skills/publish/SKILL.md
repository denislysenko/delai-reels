# Выкладка в Instagram: Dropbox → Buffer → Reels

Почему так: Buffer публикует и держит расписание, но файл не принимает. Он скачивает ролик по ссылке в момент публикации, иногда через несколько часов после того, как пост создан. Ссылка нужна публичная, прямая (сам файл, без страницы просмотра и редиректа), по https и живая до выхода поста. Прямую ссылку `dl.dropboxusercontent.com/…` даёт `publish_dropbox.py`. Обычная ссылка «поделиться» с `www.dropbox.com` не годится, Buffer об этом пишет в своей документации.

Нужно: `integrations.buffer` и `integrations.dropbox` в `harness.config.json`, `bash video/scripts/doctor.sh` → строки `Dropbox` и `Buffer key` со статусом `ok`. Чего-то нет — скажи, как подключить (`setup`, блок 5, «Выкладка в Instagram»), и остановись.

## 1. Что выкладываем

- Файл: `video/out/final-master.mp4` последнего монтажа или из `edits/<N>/`. Проверь, что это тот ролик: длительность и первый кадр (`ffprobe`, `ffmpeg -ss 1 -frames:v 1`).
- Канал: `BUFFER_CHANNEL_ID` из `video/.env` или `python3 video/scripts/publish_buffer.py channels` → спроси, куда.
- Когда: сейчас, в очередь Buffer или на время. Время пользователь называет своим; переведи в UTC (`--at 2026-11-03T07:00:00Z` для 10:00 по Москве) и повтори ему обоими.
- Обложка: Instagram берёт кадр из самого ролика. Своей картинки через Buffer поставить нельзя, можно выбрать момент: `--thumb-ms` (миллисекунды от начала). Предложи кадр с заголовком или постером, покажи его (`ffmpeg -ss <сек> -i … -frames:v 1 out/thumb.jpg`).

## 2. Подпись

Из `video/SCRIPT.md`, `captions.json` и профиля (`profile.tone`, `profile.cta`): первая строка — зацепка, своими словами, не повтор постера; 2–4 строки пользы; призыв; хэштеги умеренно (3–5). Лимит Instagram 2 196 символов. Сохрани в `video/out/post.txt` и покажи целиком. Правки — до «ок».

## 3. Ролик в Dropbox

```bash
cd video && python3 scripts/publish_dropbox.py upload out/final-master.mp4 <ГГГГ-ММ-ДД_тема>
```
Последняя строка вывода — прямая ссылка, строкой выше — папка в Dropbox (запомни для уборки). Проверь ссылку до Buffer, она должна отдавать сам файл:
```bash
curl -s -r 0-1023 -o /dev/null -w '%{http_code} %{content_type}\n' "<ссылка>"     # 200 или 206, video/mp4
```

## 4. Пост в Buffer

Сначала черновик, это поведение по умолчанию:
```bash
python3 scripts/publish_buffer.py post --channel <id> --video "<ссылка>" --text out/post.txt [--thumb-ms 1500]
```
Покажи пользователю: канал, время, подпись, кадр обложки. **Опубликовать или поставить в расписание — только после явного «да» в чате на этот пост и это время.** Одобрение одного поста не распространяется на другие.

После «да» создай пост заново с нужным режимом (черновик оставь или удали в Buffer, скажи об этом):
```bash
python3 scripts/publish_buffer.py post --channel <id> --video "<ссылка>" --text out/post.txt --at 2026-11-03T07:00:00Z
# или --now, или --queue (ближайшее свободное время в расписании Buffer)
```
Статус `error` сразу после создания — Buffer не смог взять файл или подпись; покажи текст ошибки, ничего не повторяй молча.

## 5. Дождаться выхода и убрать файл

```bash
python3 scripts/publish_buffer.py wait <post_id> --cleanup /reels/<папка>     # в фоне (run_in_background)
```
Скрипт спрашивает Buffer раз в 5 минут (лимит бесплатного тарифа — 600 запросов в сутки на весь аккаунт), на `sent` печатает ссылку на пост и удаляет папку в Dropbox, на `error` останавливается с причиной. Для поста на завтра запускай `wait` ближе к времени выхода или спроси статус потом: `publish_buffer.py status <post_id>`. Пока пост не вышел, файл из Dropbox не удаляй.

Ссылку на вышедший пост отдай пользователю и запиши в `edits/<N>/published.txt` вместе с датой и подписью.

## Если не вышло

- `There is an issue with the media` или ошибка скачивания — ссылка не прямая или файл удалён раньше времени. Проверь шаг 3 и что папка в Dropbox на месте.
- Instagram отклонил видео — сверь мастер с `delivery-specs.md` (вертикаль 1080×1920, H.264, AAC); не перекодируй без согласия.
- `ключ не принят` — новый ключ на publish.buffer.com/settings/api, пользователь вписывает сам.
- `Dropbox: вход не выполнен` / `код входа устарел` — `publish_dropbox.py login` и `connect` заново; рабочий ключ при неудачном обмене не стирается.
